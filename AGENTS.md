# Atendimento Grazing

Trabalhe em português. Use frases curtas, voz ativa e termos consistentes.
Confira branch e status antes de editar. Preserve trabalhos alheios.
O HUB é dono dos cadastros centrais, usuários e permissões. A integração existente consulta o HUB em modo somente leitura. Não copie cadastros nem crie autenticação paralela.
Não use dados reais para testes. Não envie mensagens nem ative IA, follow-ups ou automações para validar código.
Não versione credenciais, ambientes reais, backups, mídias ou dados de clientes.
SQL é manual e aditivo. Não use migrate dev, db push nem reaplique SQL histórico.
Preserve domínio, webhook, número, bancos, credenciais e backups no Drive.
Verifique o espaço livre antes de cópias, instalação ou compilação grande. Informe abaixo de 20 GB. Abaixo de 10 GB, não inicie operações de vários GB. Não faça limpeza automática.
Use componentes e tokens existentes. Remover usa X, vermelho pastel fixo com efeito no hover, com nome acessível. Fechar janelas e remover fotos ou pequenos itens podem usar apenas X cinza.
Antes de publicar: npm test, npm run typecheck, npm run lint e npm run build. Confirme saúde e acesso sem enviar mensagens.
Publicação usa npm run publicar. O comando exige checkout limpo e a revisão existente no repositório oficial. O retorno troca somente código; nunca restaura banco.
